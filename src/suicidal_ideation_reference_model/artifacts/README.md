# Packaged Artifacts

This package includes the fitted reference-model artifact used by the Python API
and CLI.

Default artifact:

- `si_xgb_full_2020_v0_1_0.joblib`

Companion metadata:

- `si_xgb_full_2020_v0_1_0.metadata.json`

The joblib file contains the fitted preprocessing pipeline and calibrated
classifier. The JSON file exposes the same high-level metadata in a
language-neutral form for review.
